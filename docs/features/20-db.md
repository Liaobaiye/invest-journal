# 数据库 JSON Store

- **ID**: `db`
- **路由**: 无
- **状态**: `server/data/db.json`
- **依赖**: 无

## 行为

- 进程内存对象；`saveDb()` 防抖 50ms 写临时文件后 `rename` 原子替换
- `flushDb()` 立即落盘（进程退出时）
- `nextId(collection)` 自增

## 集合

| 键 | 用途 |
|----|------|
| `users` | 管理员 |
| `posts` | 文章（tags/trade_data 为 JS 对象，非字符串） |
| `comments` | 评论 |
| `exchange_config` | 交易所密钥 |
| `alert_configs` / `alert_log` | 提醒 |
| `position_records` | 仓位 |
| `settings` | 站点 + 余额缓存键 |
| `counters` | 自增 |

## 文件

- `server/src/db/store.js`
- `server/src/db/seed.js`（`npm run seed`）

## 如何修改

| 需求 | 改哪里 |
|------|--------|
| 加集合 | `empty()` 增加键；repository 增删改查 |
| 换 SQLite | 保持 repository API，替换 store 底层 |
| 备份 | 复制 `server/data/db.json` |

## 隔离边界

- 单写进程；多实例会互相覆盖（与原 sql.js 锁类似，文档化限制）
- 损坏时 load 回退 empty（可扩展备份 `.bak`）
